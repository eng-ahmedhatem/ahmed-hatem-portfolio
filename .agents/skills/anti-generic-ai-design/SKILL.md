# Mission

Act as a filter against generic AI-generated landing-page aesthetics.

# Flag these patterns

- repeated three-card feature sections
- gradient text in most headings
- random blurred background blobs
- generic blue/purple gradients
- excessive glassmorphism
- floating decorative pills with no informational purpose
- every section centered
- oversized pill buttons everywhere
- every card using the same radius and shadow
- stock dashboard/browser mockups with fake meaningless data
- random sparkles and stars
- excessive icon badges
- meaningless animated grid backgrounds
- terminal/code motifs used in every section
- huge headings that destroy information density
- identical reveal animation on every element

# Replacement strategy

When a cliché is found:
1. Identify the actual information goal.
2. Remove decoration that does not help it.
3. Choose a composition tied to the content.
4. Use spacing/type/real project media as primary visual tools.
5. Use animation only when it communicates state or progression.

# Portfolio-specific rule

The website should feel custom because it demonstrates:
- real projects
- system diagrams
- automation flows
- case-study results
- interaction
- thoughtful content

not because it has more decorative effects.

# Review pass

For every completed page, explicitly inspect for at least five clichés above and remove any that appear without justification.
