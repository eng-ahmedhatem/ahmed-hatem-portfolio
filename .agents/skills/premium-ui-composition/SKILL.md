# Objective

Create a premium editorial/technical composition rather than a repeated landing-page template.

# Core rule

Never default to:
heading
paragraph
three equal cards

repeated across the page.

Before building each section, decide what visual composition best expresses its content.

# Composition vocabulary

Use a controlled variety of:
- asymmetric split layouts
- large editorial rows
- sticky narrative panels
- media-led case-study bands
- full-width technical diagrams
- numbered service rows
- compact capability clusters
- offset image/text compositions
- restrained grids
- timeline/process rails
- data/metric bands

# Recommended homepage rhythms

Hero:
- text-led split
- interactive or system-oriented visual
- avoid generic laptop mockup unless it contains actual project proof

Featured work:
- asymmetric project presentation
- give strongest projects more visual weight
- avoid same-sized cards for every project

Build / Connect / Automate:
- treat as one positioning system, not three generic feature cards

Automation:
- allow diagram/workflow composition
- consider sticky explanation + evolving visual on large screens

Process:
- numbered directional sequence
- not four decorative cards

Technology:
- categorized, compact and readable
- technology must support capabilities, not become logo wallpaper

About:
- editorial split
- concise proof and point of view

CTA:
- a strong final statement with one dominant action

# Section diversity rules

Adjacent sections should not use the same:
- alignment
- grid
- card style
- background treatment
- reveal pattern

unless consistency is intentionally required.

# Content density

Not every section needs a container full of content.
Use whitespace deliberately.

# Responsive recomposition

Do not collapse everything into a naive single column.
Preserve priority:
- key statement first
- proof second
- decoration last

# Quality questions

Before finalizing:
1. What is the visual idea of this section?
2. Why is this layout appropriate to its content?
3. Does it repeat the previous section?
4. Is there a dominant focal point?
5. Can anything decorative be removed?
